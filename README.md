# 🏥 Medical Note Classification Project

## 📌 Overview

This project classifies medical notes into disease categories such as Fever, Diabetes, Heart Disease, and Infection using Machine Learning.

---

## 🎯 Objective

To predict the disease category based on input medical text.

---

## 🧠 Technologies Used

* Python
* Scikit-learn
* Pandas
* TF-IDF
* Logistic Regression

---

## ⚙️ Methodology

1. Data collection (medical notes dataset)
2. Text preprocessing
3. Feature extraction using TF-IDF
4. Model training using Logistic Regression
5. Prediction of disease category

---

## 📊 Example

**Input:**
patient has fever and chills

**Output:**
Fever

---

## ▶️ How to Run

```bash
pip install pandas scikit-learn numpy
python main.py
```
